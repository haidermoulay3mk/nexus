# Jarvis on the web (May 2026, description only)

The first browser versions of Jarvis, originally in the GitHub repos `Jarvis`, `Jarvis-v2` and `jarvis-phone`.

| Version | What it was |
|---|---|
| **JARVIS** (web page) | A single-page "personal operating system": a gamified habit tracker with streaks, EXP and ranks, deployed as a static site. |
| **Personal Jarvis** (phone app) | The installable version (PWA): learning roadmaps, training plans, books, finance and chess goals, behind a password the user chose on first run. It grew into [`../3-nexus-web-app/`](../3-nexus-web-app/). |

**Why the files aren't here:** both shipped with their author's own routine as the default content. The public
repository only keeps code that starts empty for every user, so these versions are described rather than included.
