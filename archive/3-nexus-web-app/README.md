# NEXUS web app (description only)

A single-file dashboard installable as an app (PWA) — the step between the Python versions and today's TypeScript
NEXUS. Data lived only in the browser's local storage, behind a password the user chose on first run.

**What it had:** a daily habit and streak tracker, a learning roadmap, trackers for courses, books and languages,
training and meal plans, and a weekly review — all one HTML file with no server.

**Why the file isn't here:** it shipped with its author's own routine as the default content (personal habits,
training and meal plans). The public repository only keeps code that starts empty for every user, so this version is
described rather than included. Its ideas live on in today's NEXUS: trackers that run on typed commands, data that
stays on your own computer, and a first-run `setup` that starts from nothing.
